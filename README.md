# RecettesApp 🍽️

Application Android pour consulter et rechercher des recettes de cuisine.

## 📱 Fonctionnalités

* 🔍 Recherche de recettes
* 📋 Liste des recettes
* 📄 Détail d'une recette
* 🎨 Interface moderne Material Design
* 🧭 Navigation simple entre les écrans

## 🛠️ Technologies utilisées

* Java / Kotlin (Android)
* Android Studio
* XML (UI Layout)
* RecyclerView
* Material Design

## 📂 Structure du projet

```
app/
 ├── java/.../recettesapp
 │   ├── MainActivity
 │   ├── RecipeAdapter
 │   ├── RecipeModel
 │   └── ...
 └── res/
     ├── layout
     ├── drawable
     ├── values
     └── ...
```

## 🚀 Installation

1. Cloner le projet

```
git clone https://github.com/Rached12364/RecettesApp.git
```

2. Ouvrir avec Android Studio

3. Sync Gradle

4. Run sur émulateur ou téléphone
